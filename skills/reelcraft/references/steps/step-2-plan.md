# Step 2 — Plan

Write `reelcraft-plan.md` in the output folder, using your step 1 answers. This is
the storyboard — step 3 turns it into a render config, so be concrete: name actual
screens, actual copy, actual durations, not placeholders.

## Shared header (both modes)

```markdown
# <Title>

- Mode: marketing | training
- Format: landscape | vertical | square
- Duration target: <seconds>
- Tone: <preset> — <one-line direction>
- Visual identity: <dominant colors/fonts observed in the actual product, not invented>
- Audio direction: <mood in plain words, e.g. "upbeat but not chaotic">
```

## Marketing mode storyboard

```markdown
## The angle
<what makes this worth 20 seconds of someone's attention>

## Hook (2-3s)
<first thing on screen — must earn the next 2 seconds>

## Reveal (2-4s)
<what this is>

## Highlights (5-12s, 2-3 beats)
1. <scene: on-screen content, text overlay, transition mood>
2. ...

## Punchline / outro (2-4s)
<closing beat + CTA if any>

## Share copy draft
<one-line caption for X/LinkedIn>
```

## Training mode storyboard

```markdown
## What you'll learn
<one sentence, matches step 1 answer>

## Before (3-6s)
<starting state — screen/scene description>

## Steps
1. <step name> — duration: <s>s
   - On screen: <exact UI/action>
   - Caption/narration text: <verbatim text to display or speak>
   - What to notice: <the one thing this step teaches>
2. ...

## After / recap (5-10s)
<result state + one-line recap of what was covered>
```

Do not invent a "punchline" or CTA for training mode — it ends on the result, not
a pitch.

Keep every scene entry short enough to read in one glance — step 3 will not
re-check length, so overlong text here becomes overlong text on screen.
